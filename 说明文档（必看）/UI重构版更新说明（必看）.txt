============================================================
一、更新前请先阅读
============================================================

1. 本次属于较大规模的界面与卡组系统更新，建议不要只替换 exe。
   请解压并使用完整的新版本目录，确保模板、卡牌资源和说明文档同步更新。

2. 从旧版本升级前，建议备份以下内容：
   - config.json
   - saved_decks 文件夹
   - card_cost 文件夹
   - 自己修改过的 templates、templates_global 或其他模板资源

3. 首次启动新版本时会显示免责声明。
   必须勾选“我已阅读并理解上述风险”后才能继续使用。

4. 当前识别流程仍只支持 1280×720 模拟器分辨率。

5. 国际服在部分 MuMu 模拟器中可能出现画面偏暗问题。
   遇到识别失败时，请开启“深色识别”，并优先使用黑色背景场地。


============================================================
二、控制中心 UI 全面重构
============================================================

1. 新增固定侧边栏与统一页面导航。

2. 主界面重做为控制中心仪表盘，集中显示：
   - 设备连接状态
   - ADB 地址
   - 国服 / 国际服选择
   - 当前脚本状态
   - 当前运行时长
   - 本次对战次数
   - 当前应用卡组
   - 当前卡组费用分布
   - 实时运行日志

3. 运行控制统一为：
   - 开始运行
   - 暂停
   - 恢复
   - 停止运行

4. 新增完整日志页面，支持：
   - 查看完整运行日志
   - 按日志级别筛选
   - 按关键词搜索
   - 复制或导出日志

5. 统一深色主题、按钮、输入框、状态提示和页面间距。
   参数设置中原有的 Emoji 标识已移除，整体改为更简洁的图形化界面风格。


============================================================
三、卡组工作区重构
============================================================

原有的卡组选择、我的卡组和卡组分享功能已整合到统一卡组工作区。

1. 左侧为卡牌库，右侧为当前卡组。

2. 卡牌库支持以下筛选方式：
   - 卡牌职业
   - 卡牌费用
   - 卡牌名称
   - 卡牌 ID

3. 支持以下卡牌操作：
   - 双击添加卡牌
   - 双击移除卡牌
   - 使用按钮添加或删除
   - 将卡牌拖拽到右侧卡组区域
   - 调整同一卡牌数量

4. 支持保存卡组、加载卡组和应用卡组。

5. “加载卡组”和“应用卡组”现在具有不同含义：
   - 加载卡组：将卡组内容载入编辑区
   - 应用卡组：生成脚本实际运行所需的 card_cost 模板

6. 脚本运行期间会限制修改或切换当前卡组，避免运行模板与界面状态不一致。


============================================================
四、卡组保存格式升级
============================================================

卡组保存格式升级为版本 5。

1. 主卡组不再重复保存相同卡牌文件名，改为：

   card_id + count

   示例：
   {
       "card_id": "10021110",
       "count": 3
   }

2. 新格式能够更准确地区分普通卡、异画卡和其他同名资源。

3. 主卡组规则：
   - 总数上限为 40 张
   - 同一基础卡牌最多 3 张
   - 计入费用分布

4. 旧版本卡组仍可读取，并可迁移为新格式。

5. 保存卡组时会继续保留对应的优先级、进化优先级和特殊效果配置。


============================================================
五、新增衍生物卡组
============================================================

每一个卡组现在都包含独立的“衍生物”区域。

1. 衍生物与主卡组分开显示和编辑。

2. 衍生物不设置数量上限。

3. 同一衍生物只保存一条唯一 card_id 记录，不重复累计数量。

4. 衍生物不占用主卡组的 40 张上限。

5. 衍生物不参与费用分布计算。

6. 应用卡组时，主卡和衍生物模板仍会一同生成到 card_cost，保证脚本原有识别逻辑不受影响。

7. 卡组分享内容现在会同时包含主卡组、衍生物以及对应策略配置。


============================================================
六、重启后的卡组恢复修复
============================================================

修复重启软件后出现以下显示问题：
   - 主卡组只剩约 20 张
   - 衍生物被错误显示在主卡组中

现在应用卡组后会保存一份仅供 UI 恢复使用的活动卡组快照，其中包含：
   - 主卡组 card_id + count
   - 衍生物 card_id
   - 卡组名称
   - 对应卡组文件
   - 当前 card_cost 运行模板签名

下次启动时，只有在 card_cost 模板与快照完全一致的情况下才会自动恢复。
如果运行模板已被手动修改，界面不会强行套用旧快照，避免恢复错误卡组。

对于没有活动快照的旧版本数据，程序会尝试从 saved_decks 中唯一匹配当前运行模板。
无法唯一匹配时会保留兼容回退逻辑，不影响脚本读取 card_cost。


============================================================
七、参数设置页面重构
============================================================

原本分散的设置已重新分类并集中到统一页面。

当前可设置内容包括：
   - 拖拽速度范围
   - 最大运行时长
   - 换牌策略
   - 自动重启开关
   - 自动重启等待时间
   - 自动重启次数上限
   - 深色识别
   - 庆典模式
   - 空过模式
   - 其他已有运行参数

新增自定义背景功能：
   - 选择本地背景图片
   - 启用或关闭自定义背景
   - 调整背景透明度
   - 在设置页面预览背景效果

自定义背景路径会写入本地 config.json。
移动或删除原图片后，需要重新选择背景文件。


============================================================
八、卡牌设置页面说明
============================================================

本次对卡牌设置页主要进行 UI 整理和视觉统一，原有功能保持不变。

当前继续支持：
   - 进化前出牌优先级
   - 进化后出牌优先级
   - 进化优先级
   - 必留设置
   - 已有的出牌、攻击、进化、超进化特殊效果配置

本次没有新增尚未实现的卡牌逻辑，也没有改变现有策略执行规则。


============================================================
九、统计页面
============================================================

新增统计分析页面，目前提供：
   - 今日对战次数
   - 近 7 日每日对战次数
   - 平均对局时长
   - 平均回合数
   - 本次运行统计
   - 最近一次运行摘要

统计数据来源于现有 round_stats_*.json 文件。
旧统计文件中缺少时长或回合信息时，对应平均值可能显示为暂无数据。

以下统计功能尚未加入：
   - 胜利 / 失败检测
   - 胜率统计
   - 对手职业分布

十、已知限制与后续计划
============================================================

1. 当前仅支持 1280×720 模拟器分辨率。

2. 胜负检测、胜率和职业分布尚未实现。
